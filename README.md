### 📋 Descrição do Projeto
Este projeto foi desenvolvido em Power BI com foco na gestão e no acompanhamento de Ordens de Serviço (OS) de manutenção, contemplando duas frentes complementares: Manutenção Preventiva e Manutenção Corretiva.
O dashboard permite o monitoramento estratégico das atividades de manutenção predial e de equipamentos, facilitando o acompanhamento de indicadores operacionais por meio de gráficos interativos, cartões de KPI e filtros dinâmicos.
Os dados foram estruturados a partir de registros de ordens de serviço, com modelagem relacional e uso de medidas DAX para construção de indicadores como taxa de encerramento, quantidade de OS ativas/encerradas e distribuição por equipe, prédio e status.

---

#### ⚙️ Funcionalidades principais
Através de filtros e gráficos, é possível:

✅ Visualizar a taxa de encerramento de OS (total, mensal e semanal)  
✅ Acompanhar a quantidade de OS ativas e encerradas em tempo real  
✅ Analisar a evolução de OS abertas x encerradas por mês  
✅ Identificar a distribuição de OS por status (Fechado, Concluído, Ativo, Planejado)  
✅ Comparar o volume de OS por equipe (Refrigeração, Mecânica, Elétrica, Civil, Facilities, Hidráulica, Pintura)  
✅ Identificar o prédio e a equipe com maior número de OS ativas  
✅ Filtrar dados por equipe, equipamento, solicitante, prédio, status e intervalo de datas  
✅ Explorar dashboards integrados (Manutenção Preventiva e Manutenção Corretiva)

Este projeto utiliza dados estruturados de ordens de serviço integrados ao Power BI, proporcionando uma análise visual clara e dinâmica da operação de manutenção.

---

#### 🛠️ Ferramentas utilizadas
- Power BI Desktop
- Base de Dados de Ordens de Serviço
- Modelagem de Dados Relacional
- DAX
- Visualizações Interativas e Filtros Dinâmicos

---

‼️ É válido ressaltar que todos os dados utilizados neste projeto são fictícios, sendo aplicados apenas para fins de estudo, prática e composição de portfólio.
Este projeto demonstra não apenas domínio técnico da ferramenta Power BI, mas também a capacidade de transformar dados operacionais em informações visuais estratégicas que apoiam a tomada de decisão na gestão de manutenção.
